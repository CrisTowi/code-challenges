# Hand-picked examples per challenge

Each challenge declares 2–4 named examples (`small`, `large`, `edge-case`, `pathological`) inside its folder. The viewer picks from a dropdown to drive the regen button. The algorithm author curates the inputs that show the interesting behavior of the algorithm.

User-supplied input would be more flexible, but requires input validation UI per challenge and the algorithm author has to define the input schema. Hand-picked examples cover the cases that matter for teaching without the validation overhead.
